# 🧭 Smart Campus Navigation — CampusNav

A web-based indoor campus navigation project designed to help students, faculty, and visitors find campus locations and understand how to reach their destinations.

## 🌐 Live Demo

[Visit CampusNav](https://sbkshirsagar2007-lgtm.github.io/smart-campus-navigation-)

## 📖 About the Project

Finding classrooms, laboratories, libraries, canteens, and other facilities in a campus can be confusing, especially for new students and visitors.

CampusNav aims to simplify campus navigation through a web interface that provides campus location search, floor selection, an interactive map, and route-planning options.

## ✨ Key Features

- **Location Search:** Search for campus locations.
- **Floor Selection:** Choose between ground, first, and second floors.
- **Route Planning:** Select a starting location and destination.
- **Interactive Campus Map:** Explore campus locations through a map interface.
- **Map Views:** Switch between satellite and blueprint views.
- **QR Code Access:** Designed to provide quick access through campus QR codes.
- **Responsive Web Access:** Access the website through a browser without installing a separate application.

*Note: Feature availability may depend on the current implementation and configured campus data.*

## 🎯 Project Objectives

- Make campus navigation easier for students and visitors.
- Provide a simple and accessible interface for finding locations.
- Organize campus locations and floor information.
- Explore the use of web technologies to solve a real-world navigation problem.
